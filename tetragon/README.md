# Tetragon과 시연 정책

## 목표
선택한 행동에서 실제 Tetragon 이벤트를 수집하고 미리 준비한 정책에 따른 대응 결과를 검증한다.

## 구현
1. Linux 환경에서 설치·커널 지원·권한과 기본 프로세스 이벤트를 확인한다.
2. `policies/`에 시연용 관찰·대응 정책을 준비한다. 정책을 분리할지 여부는 실제 동작을 보고 정한다.
3. 적용 전후의 동작과 원본 이벤트 JSON을 확인해 전송 모듈 담당자에게 공유한다.
4. 프로세스 종료와 작업 거부를 구분한다. `SIGKILL`만으로 파일 쓰기 등이 실행되지 않았다고 단정하지 않는다.

## 완료 조건
정책 적용 방법, 시연 명령, 원본 이벤트, 실제 대응 결과를 재현할 수 있다. macOS Docker Desktop의 Linux VM에서 동작하는지는 미검증이다. 정책 파일은 아직 없다.
