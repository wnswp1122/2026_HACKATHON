# 24시간 대시보드 샘플

`sample` 출처로 최근 24시간의 합성 이벤트를 추가한다. 실제 수집 데이터는 변경하지 않는다.

백엔드의 `DATABASE_URL`과 `DASHBOARD_LOCATIONS_FILE` 환경변수를 적용하고 저장소 루트에서 실행한다.

```sh
backend/.venv/bin/python scripts/seed_sample_history.py
```

명시적 위치 파일을 사용하는 백엔드에서 `ATTENTION_POLICY_NAMES`에 `hack-demo-enforce,sample-risk-network`를 포함한다. 화면에서는 **예시 데이터(sample) → 전체 인스턴스 → 최근 24시간**을 선택한다.

- 3개 서버의 프로세스·파일·네트워크 이벤트와 세 차례의 위험 집중 구간을 생성한다.
- 북한·중국·러시아의 가상 위험 IP 9개와 정상 통신 목적지를 구성한다. 문서용 IP에 부여한 가상 좌표이며 실제 국가별 IP 평판 정보가 아니다. 위험 분류는 국가가 아닌 규칙명 일치를 사용한다.
- 수신 시각 기준 그래프를 채우기 위해 sample 행을 DB에 직접 저장한다. 실제 수집·전송 검증을 대신하지 않는다.
- 실행마다 새 기록을 추가하므로 필요할 때 한 번 실행한다. 별도 스키마 초기화나 기존 데이터 삭제는 하지 않는다.
- 생성 기록은 전체 sample 조회에 포함된다. 종료 후 시간이 지나면 24시간 조회 범위에서 순차적으로 제외된다.
