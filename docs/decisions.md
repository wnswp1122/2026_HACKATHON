# 현재 개발 결정

## 사용자와 합의한 제품 범위

- Tetragon 하나로 이벤트 수집과 미리 정한 정책에 따른 대응을 시연한다. Falco와 동시 도입하지 않는다.
- 우리 서비스는 대시보드·화면 알림·AI 조사 안내를 제공한다.
- AI의 YAML 수정·자동 적용과 취약점 자동 수정은 제외한다.
- 로컬 환경과 약 5시간 개발을 기준으로 한다. 실제 운영 보안 효과까지 검증한 것으로 주장하지 않는다.

## 이번 구체화에서 선택한 구현 기준

사용자가 기술 스택 선정을 요청해 아래를 선택했다. 모든 세부 선택에 대한 별도 팀 승인을 받은 것으로 표현하지 않는다.

| 선택 | 이유·상세 |
|---|---|
| Python 3.12 + FastAPI/Uvicorn + HTTPX + Pydantic | 기존 개발 환경을 활용하고 수신·검증·AI 연결을 단순화 |
| 기본 HTML/CSS/JavaScript, FastAPI 정적 제공 | 한 화면이며 빌드/CORS/별도 서버를 줄임 |
| 최근 1,000건 메모리, 2초 폴링 | 로컬 저빈도 시연. 재시작·알림 누락 한계 허용 |
| JSONL 파일 전송, 백엔드에서만 변환 | 팀 간 원본 해석 중복 제거 |
| OpenAI Responses API / gpt-5-mini | 범위가 정해진 이벤트 설명과 구조화 응답. 키/접근은 미확인 |
| 시연 파일 읽기와 probe 프로세스 종료 | 실제 악성 코드 없이 정책 전후 결과 비교 |

선정 근거와 대안: [기술 스택](tech-stack.md). 입력·출력 기준: [API 계약](api-contract.md).
