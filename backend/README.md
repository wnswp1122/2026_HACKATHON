# 백엔드

## 목표
이벤트를 수신·저장·조회하고 선택한 이벤트에 대한 AI 조사 안내를 제공한다.

## 구현
- FastAPI를 사용한다. 이벤트와 AI 책임은 `src/events/`, `src/analysis/`에 둔다.
- `POST /api/events`, `GET /api/events`, `GET /api/events/{id}`, `POST /api/events/{id}/analysis`를 구현한다.
- 저장은 우선 메모리로 한다. 재시작 시 데이터가 사라진다.
- 시연 조건에 맞는 이벤트에 경고 이유를 붙인다. 모든 이벤트를 공격으로 분류하지 않는다.
- AI 키는 환경변수로 제공하고, 외부로 전송하는 필드를 사용자에게 알린다. AI 실패 시에도 이벤트 조회가 가능해야 한다.
- 프론트엔드 제공 방식과 브라우저 접근 설정은 구현 단계에서 정한다.

## 완료 조건
실제 이벤트가 수신·조회되고 선택한 이벤트의 AI 결과 또는 실패가 반환된다. 아직 API 서버는 구현되지 않았다.
