# 이벤트 화면

## 목표와 입력

[API 목록·상세](../../../docs/api-contract.md)만 사용한다. Tetragon 원본의 중첩 필드를 화면에서 파싱하지 않는다. `eventType`, `status`, `source`의 문구를 화면용으로 변환한다.

## 상태와 갱신

- 목록, 선택 ID, 필터, 현재 serverSessionId, 본 ID 집합, 마지막 성공 시각을 관리한다.
- 첫 조회의 모든 ID를 본 것으로 기록하고 기존 이벤트를 새 경고로 알리지 않는다.
- 이후 처음 본 attention ID만 알린다. 같은 목록을 반복 조회해도 재알림하지 않는다. sample이면 배너에도 예시 표시.
- serverSessionId가 바뀌면 이전 목록·선택·분석·본 ID를 초기화하고 새 목록을 첫 조회처럼 처리한다.
- 본 ID는 최신 2,000개까지만 보관한다. 단일 시연에서의 중복 배너를 방지하기 위한 메모리 상태다.
- 상세가 404이면 보관 범위에서 없어졌다고 안내하고 선택을 해제한다.
- PROCESS_EXIT/OTHER도 목록에서 볼 수 있게 하고 모르는 target은 '-'로 표시한다.

## 결과 표현

reportedAction이 있으면 `보고된 동작: <원본값>`으로 표시한다. outcome=unknown은 `실제 결과: 확인 불가`다. 빨간 차단 성공 배지나 차단 성공 건수를 만들지 않는다. policyName이 없으면 정책명 미상. null 발생 시각은 수신 시각으로 바꿔 쓰지 않는다.

## 확인

동일 이벤트 2회 조회 시 배너 1회, 새 경고 1건 추가 시 새 배너, observed 이벤트에는 배너 없음, 재시작 시 과거 배너 반복 없음. 최근 100건 밖 이벤트를 알리지 못할 수 있다는 한계는 메인 문서를 따른다.
