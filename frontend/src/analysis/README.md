# AI 분석 화면

## 목표

선택한 이벤트에 대한 조사 안내를 요청한다. 서버 설명은 선택 입력이며 2,000자 제한. [API 계약](../../../docs/api-contract.md)의 네 목록을 별도 영역으로 보여준다.

## 상태

- 미요청: 분석 버튼과 외부 전송 정보 안내.
- 진행 중: 버튼 비활성화, 로딩 표시. 같은 이벤트에 중복 요청하지 않는다.
- 성공: eventId 확인 후 네 목록과 모델·생성 시각 표시.
- 실패: 503은 설정 필요, 504는 시간 초과, 502는 제공자/형식 오류, 404는 이벤트 없음. 사용자가 재시도 가능.

브라우저에 AI 키를 저장하거나 OpenAI를 직접 호출하지 않는다. 모든 호출은 백엔드를 통한다. 화면 전환 중 늦게 도착한 결과를 다른 이벤트에 표시하지 않는다. API 실패 시 예시 답변으로 성공 상태를 꾸미지 않는다.
