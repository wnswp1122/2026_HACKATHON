# 대시보드

## 목표
실제 이벤트, 새 경고와 AI 조사 안내를 한 화면에서 보여준다.

## 구현
- 별도 빌드 도구 없이 HTML·CSS·JavaScript로 시작한다.
- `src/events/`에 목록·상세와 주기 조회 기반 화면 알림을, `src/analysis/`에 AI 요청과 결과 표시를 둔다.
- 백엔드 API 계약을 확인하기 전에는 예시 데이터로 화면을 준비한다.
- 정책 설정, 이벤트에서 확인된 대응 동작과 별도 확인된 결과를 구분한다. 결과를 알 수 없으면 확인 불가로 표시한다.
- AI로 전송하는 정보와 호출 실패를 화면에 표시한다.

## 완료 조건
실제 수신 이벤트와 새 경고를 보여주고 선택한 이벤트의 AI 안내를 확인할 수 있다. 화면은 아직 구현되지 않았다.
