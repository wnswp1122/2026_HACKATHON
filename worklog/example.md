# 예시: AI 협업 작업 기록

> 이 문서는 템플릿 사용법을 보여주기 위한 가상의 예시입니다.

- 관련 이슈: #1

## 해결하고자 하는 문제

팀원이 AI에게 작업을 맡길 때 문제와 완료 조건이 흩어져 있으면 작업의 의도와 결과를 확인하기 어렵습니다.

## 해결 방법

이슈에 문제와 완료 조건을 적고, 작업하면서 해결 방법과 고민을 보완합니다. PR에는 실제 변경과 확인 결과를 남깁니다.

## 고민한 것

이슈와 PR에 같은 내용을 반복하면 기록을 유지하기 어렵습니다. 상세한 맥락은 이슈에 두고 PR에서 관련 이슈를 연결합니다.

## 결과와 다음 할 일

- 예시 기록을 추가해 각 항목의 작성 방식을 보여줍니다.
- 직접 확인한 내용: 예시 문서가 저장소의 worklog 안내 형식을 따릅니다.
- 확인하지 못한 내용: 실제 팀 작업에서 이 방식이 충분한지는 아직 확인하지 않았습니다.
